Design System · v1.0

PostOpGuard

Foundations, components, and patterns for the autonomous post-operative recovery safeguard. Tokens are CSS custom properties — never hardcode values. Components live in shared.jsx.

Principles

Six rules that hold every screen together.

01

Trust over flash

Stripe-clean, EMR-clear. The brand gradient appears only on the mark.

02

Glass box for decisions

LLM extracts. Lua decides. Always show the trace.

03

Calm under load

Red = page on-call. Amber = watch. Green = no action. Don't overuse red.

04

Audio is canonical

Waveform + prosody lead. Transcript supports.

05

Voice-first for patients

One primary action. 44px+ targets. Status orb communicates phase.

06

Tag the provenance

Every event names its source: Oban, LLM, Lua, System.

Code blocks

Hand-written highlighter, 12px Plex Mono, line-height 1.55. Token classes: .c-comment, .c-string, .c-kw, .c-num, .c-type.

-- DVT_Risk_Hip_v2 · live since 2026-04-29
function evaluate(patient, today)
  local warmth      = today.calf_warmth == true
  local risk        = 0
  if warmth then risk = risk + 0.35 end

  if risk >= 0.75 then
    return Alert.new {
      severity = "critical",
      sla_min  = 30
    }
  end
end

Patterns to avoid

If a screen reaches for any of these, push back.

✕ Gradient backgrounds

Brand gradient is for the mark only. Never page, card, or button.

✕ Drop shadows on cards

1px hairline borders only.

✕ Decorative icons

Every icon must mean something clinical or navigational.

✕ Sentence-case pills

Pills are mono uppercase short codes. For lowercase metadata use .mono-tag.

✕ Emoji

Use icons from Icon. Period.

✕ Inventing accent colors

Extend tokens or reach for the existing accent.

✕ AI as the decider

Always frame as: LLM extracts → Lua decides.

✕ Transcript without audio

Audio is the clinical source-of-truth.

✕ Animations on data

Sparkline lines do not animate; numbers don't count up.

✕ Toasts and modals

Use the inline alert banner pattern instead.
