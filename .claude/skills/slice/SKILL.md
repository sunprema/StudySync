# /slice - Implement a roadmap slice

When invoked with a slice number:

1. Read the roadmap doc and locate the slice's sub-tasks.
2. Explore relevant existing modules before writing code.
3. Implement domain -> resource -> LiveView -> Svelte -> tests in that order.
4. Run `mix test` and `mix format` until clean.
5. Update the roadmap to mark sub-tasks complete.
6. Summarize files changed and test count.
